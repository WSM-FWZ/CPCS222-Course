# CPCS 222 — GitHub Pages Deployment Guide

## Files to Upload

Upload **only the contents of this `deploy/` folder** to your GitHub repository root.

Your GitHub repo root should look exactly like this after upload:

```
index.html
pages/
  chapter1-lesson1-1.html
assets/
  css/
    main.css
  js/
    app.js
engine/
  json_loader.js
  renderer.js
  navigation.js
  quiz_engine.js
```

Do **not** upload `archive/`, `outputs/`, `contents/`, `processed/`, `logs/`, or any other development folder.

---

## How to Enable GitHub Pages

1. Push the deploy folder contents to your GitHub repository (e.g. `your-username/cpcs222`).
2. Go to **Settings → Pages** in your repository.
3. Under **Source**, select **Deploy from a branch**.
4. Choose branch `main` (or `master`) and folder `/ (root)`.
5. Click **Save**.

GitHub will publish the site within 1–2 minutes.

## Troubleshooting

### CSS not loading (page looks unstyled)
- Check the `<link rel="stylesheet">` path in the HTML file.
- From `index.html` it must be `./assets/css/main.css`.
- From `pages/*.html` it must be `../assets/css/main.css`.
- Never use a path starting with `/`.

### JS not loading (blank lesson view / "Loading lesson…" spinner stuck)
- All 5 scripts must load in this order from `chapter1-lesson1-1.html`:
  1. `../engine/json_loader.js`
  2. `../engine/quiz_engine.js`
  3. `../engine/renderer.js`
  4. `../engine/navigation.js`
  5. `../assets/js/app.js`
- Open browser DevTools → Console. Any `404` on a script means the path is wrong.

### JSON not loading
- All lesson data is **embedded inline** inside `engine/json_loader.js`.
- There are no external `.json` file fetches. If the lesson doesn't load, the issue is with a JS script path (see above), not a JSON file.

### Page stuck on "Loading lesson…"
- This means `json_loader.js` or `navigation.js` failed to load.
- Check DevTools → Network tab for any red (failed) requests.
- Confirm the `engine/` folder was uploaded to GitHub.

### "Home" breadcrumb link goes to 404
- The breadcrumb is generated by `engine/navigation.js`.
- It links to `../index.html` — correct as long as your homepage is `index.html` at the repo root.

### Dark mode doesn't persist across pages
- Both pages store the theme in `localStorage` key `cpcs222-theme`. This works on GitHub Pages as long as both pages are on the same origin (same repo domain). No fix needed.
